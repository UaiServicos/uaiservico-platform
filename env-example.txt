# Copie este conteúdo para um arquivo chamado .env na raiz do projeto

# Database
DATABASE_URL="postgresql://username:password@localhost:5432/uaiservico_db"

# JWT Secret
JWT_SECRET="fallback-secret-key"

# Email Configuration (Configuração completa para envio de emails)
SMTP_SERVICE="gmail"
SMTP_USER="seu-email@gmail.com"
SMTP_PASS="sua-senha-de-aplicativo"
SMTP_FROM="UAIServiço <seu-email@gmail.com>"

# Application URL
NEXT_PUBLIC_BASE_URL="http://localhost:3000"

# ========================================
# INSTRUÇÕES DE CONFIGURAÇÃO:
# ========================================
# 1. Crie um arquivo chamado .env na pasta raiz
# 2. Copie o conteúdo acima para o arquivo .env
# 3. Configure o banco de dados PostgreSQL:
#    - Substitua "username" pelo seu usuário do PostgreSQL
#    - Substitua "password" pela sua senha do PostgreSQL
#    - Substitua "localhost:5432" pelo host e porta do seu banco
#    - Substitua "uaiservico_db" pelo nome do seu banco
# 4. Configure o email:
#    - Substitua "seu-email@gmail.com" pelo seu email
#    - Para Gmail: Use uma "Senha de Aplicativo" (não sua senha normal)
#    - Para outros provedores: Use sua senha normal
# 5. Salve o arquivo
# 6. Execute: npx prisma migrate dev
# 7. Reinicie o servidor (npm run dev)
# 8. Teste a configuração: GET /api/test-email?action=test-config

# ========================================
# SERVIÇOS SUPORTADOS:
# ========================================
# Gmail: SMTP_SERVICE="gmail" (use senha de aplicativo)
# Outlook: SMTP_SERVICE="hotmail"
# Yahoo: SMTP_SERVICE="yahoo"
# iCloud: SMTP_SERVICE="icloud"
# Zoho: SMTP_SERVICE="zoho"
# Custom SMTP: Configure manualmente com host/porta

# ========================================
# COMO CRIAR SENHA DE APLICATIVO (GMAIL):
# ========================================
# 1. Acesse: https://myaccount.google.com/security
# 2. Ative a "Verificação em duas etapas" se não estiver ativa
# 3. Vá em "Senhas de aplicativo"
# 4. Selecione "Outro (nome personalizado)"
# 5. Digite "UAIServiço Platform"
# 6. Copie a senha gerada e use em SMTP_PASS

# ========================================
# CONFIGURAÇÃO DO POSTGRESQL:
# ========================================
# Para desenvolvimento local:
# 1. Instale PostgreSQL: https://www.postgresql.org/download/
# 2. Crie um banco de dados: CREATE DATABASE uaiservico_db;
# 3. Configure a DATABASE_URL no .env
# 4. Execute: npx prisma migrate dev

# Para produção (Vercel):
# 1. Use um serviço como Neon, Supabase, ou Railway
# 2. Configure a DATABASE_URL nas variáveis de ambiente do Vercel
# 3. Execute: npx prisma migrate deploy

# ========================================
# TESTANDO A CONFIGURAÇÃO:

# 3. Testar banco: npx prisma studio
